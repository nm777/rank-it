# Rank It

Rank It helps people capture what they want to remember and answer questions using their own memories.

## Language

**Memory**:
A private, dated account of something a person wants to remember about any subject. A memory may include a rating.
_Avoid_: Note (when naming the saved entry)

**Capture date**:
The date a person saved a memory.

**Experience date**:
When the event or experience described in a memory took place. It can be approximate or unknown.

**Supporting memory**:
A saved memory whose dated wording provides evidence for a claim or suggestion in an answer.

**Import batch**:
The collection of material a person imports together in one action. The same message can belong to more than one batch.

**Correction**:
A clarification that identifies an earlier claim as mistaken. A correction to imported material preserves what the original author said.
