# Host each tester’s private collection

Rank It will store each tester’s private collection in a hosted account. This lets a tester import a mailbox on a laptop and open a supporting memory on a phone without first building device synchronization.

For the pilot, Laravel authenticates testers through local Rank It accounts stored in PostgreSQL. Each account owns one private collection.

Registration requires an invitation so the operator controls who can import material and use Rank It–funded inference during the pilot.
