# Use external AI to draft answers from selected passages

For Ask my memory, Rank It retrieves supporting passages from the tester’s private collection and may send the question and those passages to an external AI provider to draft an answer. This lets the pilot evaluate answer quality while limiting the material disclosed per question. Rank It keeps the original wording and links each factual claim to its supporting passage.

During development and the pilot, Rank It pays for inference across indexing and answer generation. Self-hosted models run on Rank It’s infrastructure, and external model calls use Rank It’s provider account. Testers can import memories and ask questions using only their Rank It account.
